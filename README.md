## AxGlyph 是什么，数码荔枝和它是什么关系

AxGlyph 是一款 Windows 平台的矢量绘图软件，开发方和公式编辑器 AxMath 是同一个团队，官方站点上 AxMath、AxGlyph、AxCells 三个产品放在一起卖。它的定位很明确，就是给写论文、做课件、画工程图的人准备的工具，不是给平面设计师做商业视觉的。

能画的东西大致分三类：

- 工程与科研图：流程图、电路图、化学式、坐标系曲线
- 数据图：折线图、柱状图、饼图，支持模板和节点控制
- 公式混排：内置精简版 AxMath，图形里可以直接嵌数学公式

它有一个别的绘图工具不太常见的功能，就是 OLE 嵌入。画好的图能作为对象直接插进 Word 或 WPS，后面要改的时候双击回到 AxGlyph 里编辑，不用每次重新导出图片。导出方面支持 PDF 矢量输出，也能存成 BMP、JPG、PNG、GIF。

数码荔枝是渠道，不是开发方。它做的是正版软件分销，卖的是官方激活码，软件本身的更新、激活服务器、技术支持都归开发方。这个关系要分清楚，因为后面涉及售后的部分，渠道能帮你处理的是发货和订单问题，激活政策以官方为准。
